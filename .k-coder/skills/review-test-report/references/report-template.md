**总体结果**: PASS / FAIL / PARTIAL_FAIL / BLOCKED

### 汇总指标

- **通过数**: _

- **命令**: `command`
- **结果**: PASS / FAIL
- **错误/警告**: _（如有）

### 2. 测试执行明细
- **命令**: `command`
- **按项目/套件统计**:
  - `ProjectName`: Pass: X, Fail: Y, Skipped: Z
