# 需求文档名称 → 目录与文件命名

根据**需求文档标题**（钉钉 `get_document_info.name` 或本地文件名去扩展名）自动推导本地路径与钉钉目录结构。

## 拆分规则

以**第一个横杠**为界拆分（支持 `-` / `－` / `—` / `–`，含半角、全角）：

| 部分 | 含义 | 用途 |
|------|------|------|
| **前半段** | 需求分组名 | 子文件夹名称 |
| **后半段** | 设计主题 | 开发设计文档标题（不含「开发设计」后缀） |

### 示例

| 需求文档名称 | 需求分组（文件夹） | 设计主题 | 开发设计文档名 |
|--------------|-------------------|----------|----------------|
| `入职流程改进－业务流程信息变更提效` | 入职流程改进 | 业务流程信息变更提效 | `业务流程信息变更提效开发设计` |
| `离职社保欠款测算-一期` | 离职社保欠款测算 | 一期 | `一期开发设计` |
| `用工关系-流程变更` | 用工关系 | 流程变更 | `流程变更开发设计` |

拆分后 **trim** 首尾空格；分组名、主题名均不得为空，否则视为无横杠。

## 无横杠时的回退

需求名称中**不含**上述横杠，或拆分后任一段为空：

| 字段 | 值 |
|------|-----|
| 需求分组 | （无，不建子文件夹） |
| 设计主题 | 需求文档全称 |
| 开发设计文档名 | `{需求文档全称}开发设计` |

## 本地路径

```
有分组：
D:\1.CursorProject\文档\{项目名}\02-技术文档\{需求分组}\{设计主题}开发设计.md

无分组：
D:\1.CursorProject\文档\{项目名}\02-技术文档\{设计主题}开发设计.md
```

- 子目录 `{需求分组}` **不存在则新建**
- 同目录已有 `详细设计-{设计主题}.md` 等同主题文件时，优先沿用已有命名风格

## 钉钉目录

根目录固定为 **开发提测文档**（`folderId=3xRN9bGQyw4Jbo6OQa6N8zXPADKnorv6`）。

```
有分组：
  list_nodes(开发提测文档) → 查找名为 {需求分组} 的子文件夹
  → 不存在则 create_folder(name={需求分组}, folderId=开发提测文档)
  → copy_document(targetFolderId={子文件夹 nodeId})
  → rename_document(newName={设计主题}开发设计)

无分组：
  copy_document(targetFolderId=开发提测文档)
  → rename_document(newName={设计主题}开发设计)
```

**禁止**在开发提测文档根目录或子目录留「详细设计模板*」名称的文档。

## 查重与更新

1. 在**目标子文件夹**（或根目录）内 `list_nodes`，按 `{设计主题}开发设计` 查同名文档
2. 用户提供了已有设计 nodeId → 直接更新该文档
3. 同名已存在 → 默认覆盖更新；用户要求时可新建 `-v1.x` 副本

## 用户覆盖

| 用户显式指定 | 行为 |
|--------------|------|
| 需求主题 / 文档标题 | 覆盖「设计主题」，分组仍从需求文档名解析（若用户同时给分组名则覆盖分组） |
| 已有设计 nodeId | 更新该文档，不重命名路径 |

## 获取需求文档名称

| 来源 | 方式 |
|------|------|
| 钉钉 | `get_document_info(nodeId)` → `name` |
| 本地 .md | 文件名去 `.md` |
| 本地 .docx/.xlsx | 文件名去扩展名；正文首行标题可作校验 |
| 用户粘贴 | 对话中「需求文档名称：xxx」 |

优先级：钉钉/本地文件元数据 > 用户对话指定 > 从正文 H1 推断（最后手段）
