# 详细设计模板大纲结构（1.7.2）

生成开发设计时**必须严格按此顺序**组织正文，**禁止**重复章节、乱序或在大纲外追加一级标题。

## 文档结构（自上而下唯一顺序）

```
[保密块 + 变更记录]          ← copy 模板保留，非正文生成范围
# **1、 设计概述**
  ## **1.1 运行环境**
  ## **1.2 需求背景**
  ## **1.3  架构设计方案**   ← 1.3 与「架构」之间两个空格
# **2、 总体方案**
  ## **2.1 技术方案**
  ## **2.2 存储方案**
  ## **2.3 消息队列**（可选）
  ## **2.4 系统交互**（可选）
  ## **2.5 模块交互**（可选）
  ## **2.6 DFD图**
  ## **2.7 兼容分析**
  ## **2.8 事件设计**
  ## **2.9 客户影响分析**
  ## **2.10 故障分析**
# **3、 系统详细设计**
  ## **3.1 主要功能说明**
  ## **3.2 次要功能说明**
  ## **3.3 系统一（<模块名>）**
    ### **3.3.1 功能点清单**
    ### **3.3.2 服务与数据库关系**
    ### **3.3.3 功能点 1（<名称>）**
      #### 特性设计 / 设计细节 / 数据库设计 / …
    ### **3.3.4 功能点 2（<名称>）**
    …（按功能点递增 3.3.N，无功能则省略后续 3.3.x）
# **4、 事件分析**
# **5、 日志要求**
# **6、 安全设计**
  ## **6.1 网关方案**
  ## **6.2 用户权限方案**
  ## **6.3 隐私保护**
# **7、 接口设计**
  ## **7.1 接口地址**
  ## **7.2 <系统名称>**
    ### **7.2.1 错误码**
    ### **7.2.2 接口列表**
  ## **7.3 定时服务**          ← **正文必须在此结束**（无则写「不涉及」）
```

## 一级章节（# **N、**）清单

| 序号 | 标题 | 必填 |
|------|------|------|
| 1 | 设计概述 | 是 |
| 2 | 总体方案 | 是 |
| 3 | 系统详细设计 | 是 |
| 4 | 事件分析 | 是 |
| 5 | 日志要求 | 是 |
| 6 | 安全设计 | 是 |
| 7 | 接口设计 | 是 |

**全文仅允许上述 7 个一级章节各出现 1 次。**

## 2.x 子节（第 2 章固定 2.1～2.10）

不可跳过编号；无内容时写「不涉及」或空表，**仍保留章节标题**。

## 3.3 功能点扩展规则

- 至少 **3.3.1**、**3.3.2**；功能点从 **3.3.3** 起编
- 每个功能点含：特性设计（九项表）、设计细节、数据库设计（无 DDL 则说明「不涉及」）
- 多个系统时复制 **3.3** 块为「系统二」——模板默认仅「系统一」，按需扩展

## 7.2 / 7.3 结尾规则

- **7.2.2** 下含 7.2.2.1 接口列表、7.2.2.2 外部系统、7.2.2.3 接口封装（无则写「不涉及」）
- **7.3 定时服务** 为最后一节；无定时任务时：

```markdown
## **7.3 定时服务**

不涉及
```

## 本地正文提取范围

钉钉写入时，正文 Markdown **从** `# **1、 设计概述**` **起，到** `## **7.3 定时服务**` **段结束**，**不得**包含保密块与变更记录（已由模板 copy 保留）。

## 写入后校验（必做）

| 检查项 | 预期 |
|--------|------|
| `# **1、 设计概述**` 出现次数 | **1** |
| `# **7、 接口设计**` 出现次数 | **1** |
| 最后一个一级章节 | **7、 接口设计** 或其子节 **7.3** |
| `7.3` 之后 | 无 `# **1、`** 等重复一级标题 |
| 章节顺序 | 1→2→3→4→5→6→7 单调递增 |

校验失败则**不得**交付，需修正 append 顺序或正文后重传。
