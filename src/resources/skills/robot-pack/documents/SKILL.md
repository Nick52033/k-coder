# Documents

Create clear Markdown with stable headings, concise prose, usable tables, valid links, and source attribution. Follow repository placement rules, normally docs/ for generated Markdown. Preserve user-supplied facts and label assumptions.

Use a real documents plugin or supported runtime for DOCX or online document operations; the built-in compatibility Skill does not claim those capabilities. Do not substitute container-only scripts, guessed converters, or plaintext credentials. Read references/document-boundaries.md when choosing an output format.
