# Create Plan

Use a plan for work with multiple dependent steps or meaningful verification. Keep steps concrete and outcome-oriented, with at most one active step. Mark a step complete only when its stated deliverable exists.

Revise the plan when evidence changes the route. Do not add ceremonial steps, duplicate the host workflow, or mark all items complete at the end without tracking progress. The plan is coordination state, not authorization for destructive or external actions.
