# PRD Delivery Review

Assemble the approved intake, scope, stories, requirements, flows, states, and acceptance criteria into one coherent PRD. Maintain traceability between goals, user stories, functional requirements, and verification.

Review four dimensions: coverage, internal consistency, implementation feasibility, and risk. Check terminology, permissions, data ownership, failure and recovery behavior, security and privacy, dependencies, rollout, compatibility, analytics, and explicit exclusions as applicable.

Report findings by severity and resolve contradictions before declaring the PRD ready. Format Markdown under the repository's documentation convention. DOCX or external publication requires a real supported integration and explicit authorization.
