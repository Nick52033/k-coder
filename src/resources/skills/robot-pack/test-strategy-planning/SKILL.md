# Test Strategy Planning

Start from product risks and public contracts. Define in-scope behavior, explicit exclusions, test levels, supported platforms, environments, fixtures, dependencies, observability, and acceptance gates. Rank scenarios by likelihood, impact, and detectability.

Cover functional, integration, end-to-end, performance, security, accessibility, compatibility, cancellation, and recovery concerns only where relevant. Map each material risk to a test method and evidence source. State prerequisites and limitations instead of inventing coverage.
