# Test Report Generation

Report the tested revision, environment, scope, commands or workflows, and result counts. Link each conclusion to fresh evidence. Separate passed, failed, blocked, skipped, and untested work; do not turn absence of evidence into a pass.

Summarize defects by severity, affected behavior, reproducibility, and disposition. Include coverage limitations, flaky or environment-dependent results, performance and security findings, release recommendation, and residual risk. Keep the report concise enough for a release decision while preserving exact failure details.
