# 对话图片识别与预览修复验证

日期：2026-09-10。任务：P10-169。契约：ADR 0058。

## 修复结果

- 普通 Chat Completions 模型的显式 supportsVision 声明覆盖 DeepSeek 名称启发式，避免支持视觉的网关别名被强制变成纯文本路径。保留工作区已有路由修正并补齐契约回归；显式 DeepSeek 传输仍拒绝视觉请求。
- 会话压缩保留最近一个图片输入批次，恢复时从原始用户事件取回像素，纯文本 Provider 不获得图片内容。
- 回答里的 HTTP(S)、栅格 data URL、工作区图片和严格浏览器截图制品名展示缩略图，并可点击打开已有全屏预览；Escape、关闭和焦点恢复可用。失败有明确提示。
- Markdown AST 转换保留代码、普通链接和完整/折叠引用链接；流式输出尚未闭合的代码/引用不会触发截图读取。
- 本地图片读取绑定当前线程工作区，支持规范化后的工作区内绝对路径。拒绝无项目线程、越界、父级遍历、目录联接、目录、非栅格内容和超限文件；浏览器截图读取也验证规范化目录与文件并有界读取。

实际启动 `pnpm tauri dev --no-watch --config src-tauri/target/image-validation.json`，标识 `com.kcoder.validation.images`，Vite 1462，WebView2 调试端口 9402；运行 `scripts/validate-images-native.cjs`。

本机 HTTP 测试 Provider 使用 deepseek-flash 别名、普通 Chat Completions 和 supportsVision=true。脚本通过输入框粘贴 640×360 测试图并发送，检查实际 HTTP 请求包含逐字节一致的 image_url；回答返回本地路径、远程地址、内嵌图和截图制品。五类图片均检查解码尺寸并实际点击打开弹层。

截图：`docs/图片预览原生验证.png`。原生结果：`src-tauri/target/image-native-result.json`；Rust 日志：`src-tauri/target/image-rust-tests.log`。测试 Provider 的响应是确定性夹具，证明客户端传输与展示链路，不代表第三方模型的实际视觉理解能力；没有调用付费模型。
