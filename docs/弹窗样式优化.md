# 🎨 弹窗样式优化 - 最终方案

## 问题

原来的授权弹窗：
- ❌ 全屏黑色遮罩，遮挡整个界面
- ❌ 按钮文字是英文（"Yes", "No"）
- ❌ 样式过于突出，打断用户体验
- ❌ 类似模态对话框，让用户感觉被"打断"

## ✅ 改进后

参考 CodeBuddy 的设计，改成：
- ✅ 轻量级内联卡片，不遮挡界面
- ✅ 按钮文字改为中文："允许一次"、"本会话都允许"、"拒绝"
- ✅ 标题改为："确认执行 [工具名]?"
- ✅ 自然融入对话流，不打断用户体验

## 📝 具体修改

### 1. CSS 样式 ([App.css](src/App.css))

**之前**：
```css
.claude-approval { 
  place-items: center; 
  background: rgba(0,0,0,.42);  /* 全屏黑色遮罩 */
}

.claude-approval-panel {
  box-shadow: 0 20px 60px rgba(0,0,0,.34);  /* 强阴影 */
  border: 1px solid var(--color-accent);
}
```

**现在**：
```css
.claude-approval {
  position: relative;
  display: flex;
  justify-content: center;
  align-items: flex-start;
  padding: 20px;
  background: transparent;  /* 无遮罩 */
  pointer-events: none;  /* 不阻止背景交互 */
}

.claude-approval-panel {
  width: min(480px, calc(100vw - 40px));  /* 更小的宽度 */
  padding: 16px;  /* 紧凑内边距 */
  box-shadow: 0 4px 16px rgba(0,0,0,.12);  /* 轻阴影 */
  pointer-events: auto;  /* 只有卡片本身可交互 */
}
```

### 2. 组件文字 ([PatchReviewDialog.tsx](src/components/PatchReviewDialog.tsx))

**按钮文字**：
```typescript
// 之前
{ value: "once", label: "Yes", description: "仅本次调用放行" }
{ value: "session", label: "Yes, allow this tool for this session", ... }
{ value: "reject", label: "No" }

// 现在
{ value: "once", label: "允许一次", description: "仅本次调用放行" }
{ value: "session", label: "本会话都允许", description: "本会话内同类操作不再询问" }
{ value: "reject", label: "拒绝" }
```

**标题**：
```typescript
// 之前
Allow {request.toolName}{targetLine ? ` to ${targetLine}` : ""}?

// 现在
确认执行 {request.toolName}{targetLine ? `: ${targetLine}` : ""}?
```

**提示文字**：
```typescript
// 之前
placeholder="Tell K-Coder what to do instead"
hint: "Esc to cancel"

// 现在
placeholder="告诉 k-Coder 应该怎么做"
hint: "按 Esc 取消 · 按数字键快速选择"
```

3. 背景界面依然可见（虽然不可交互）

5. 按钮文字清晰："允许一次"、"本会话都允许"、"拒绝"
6. 更自然的交互流程
