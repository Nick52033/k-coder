    const detail = await readThread(threadId);
    if (turn 已结束) break;
    await sleep(200ms);
  }
}

## 🎯 核心技术要点

### 问题根源
1. **前端状态** (`activeTurnId`) 被清除了
2. **后端状态** (`active_turns`) 还保留着
3. 发送新消息时检测到冲突 → 弹窗

### 解决方案
- 前端发送消息前，轮询检查后端状态
- 确认 turn 真正结束后，才发送新消息
- 超时保护（2秒）避免无限等待

### 样式改进
- 从全屏模态对话框 → 内联轻量卡片
- 移除深色遮罩，保持背景可见
- 中文按钮，更清晰的交互
