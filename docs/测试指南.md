## 🧪 快速测试指南

### 步骤 1：重新加载应用

```bash
# 1. 停止旧服务（找到端口 1420 的进程并停止）
netstat -ano | findstr :1420
# 记下 PID，然后：
taskkill /F /PID <进程ID>

# 2. 构建新版本
npm run build

# 3. 启动开发服务器
npm run dev
```

### 步骤 2：强制刷新浏览器

在浏览器中按：
- **Windows**: `Ctrl + Shift + R` 或 `Ctrl + F5`
- **Mac**: `Cmd + Shift + R`

### 步骤 3：测试场景

#### 场景 A：正常使用（应该正常工作）
1. 打开 http://localhost:1420
2. 发送一条消息："你好"
3. 等待响应完成
4. 发送另一条消息："继续"

**期望结果**：✅ 正常发送，无弹窗

#### 场景 B：快速连续发送（修复的核心场景）
1. 发送一条消息："写一段代码"
2. **立即**（在响应期间）发送另一条消息："停止"
3. 观察控制台（F12）

**期望结果**：
- ✅ 控制台显示："检测到已存在的 activeTurnId，正在清除..."
- ✅ 控制台显示："后端 turn 已清除"
- ✅ 新消息正常发送
- ✅ **不会弹出**"a turn is already active"确认框

#### 场景 C：错误恢复（测试容错性）
1. 发送消息触发某个错误
2. 看到错误提示
3. 立即发送新消息

**期望结果**：
- ✅ 自动清理错误状态
- ✅ 新消息正常发送
- ✅ 不会弹窗

### 步骤 4：验证日志

打开浏览器控制台（F12），应该看到类似：

```
检测到已存在的 activeTurnId，正在清除... <turn-id>
取消现有 turn 失败（可能已完成） [如果 turn 已自然结束]
后端 turn 已清除
```

### 如果还是出现弹窗

**临时解决**：
1. 点击"允许一次"
2. 按 `Ctrl + Shift + R` 使用紧急重置
3. 等待几秒再发送消息

**永久解决**：
1. 确认浏览器已强制刷新（清除缓存）
2. 确认开发服务器是最新构建
3. 查看控制台错误日志
4. 如果问题持续，重启开发服务器

### 成功标志

- ✅ 快速连续发送消息不会弹窗
- ✅ 控制台显示清理日志
- ✅ 错误会在 5 秒后自动消失
- ✅ 输入框显示清晰的状态提示
