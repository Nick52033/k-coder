# ADR 0035：显式无项目会话边界

- 状态：已接受
- 日期：2026-08-15
- 关联：P6-001、P10-040、P10-056、P10-092、P10-095、P10-103

## 背景

输入区项目选择器只能在已有项目之间切换或新建项目。用户需要像 Codex 一样从左下角明确选择“不在项目中”，用于不依赖本地仓库的一般对话。

现有线程仅用可空的 `workspace_path` 表示工作区：新线程会立即绑定当前工作区，旧线程没有绑定时则在首次执行前惰性绑定。若只在前端增加“不在项目中”标签，模型、项目指令、扩展、文件工具和 Shell 仍会访问当前工作区，界面状态会与真实授权边界冲突。

## 决策

1. `thread_created` 事件增加默认值为 `true` 的 `in_project` 字段，`ThreadSummary` 和 SQLite `sessions.in_project` 投影同一事实。旧事件缺少该字段时按项目线程迁移，继续保留首次执行前的惰性绑定兼容。
2. `create_thread` 接收宿主提供的可选 `inProject`。默认或 `true` 时创建并绑定当前规范工作区；`false` 时创建显式无项目线程，保持 `workspace_path = null`。
3. 无项目线程不能再绑定工作区，fork 必须保留无项目状态。该约束在 Repository 执行，不能依赖前端分组或模型参数。
4. 无项目 Turn 不加载项目指令、项目 Skill、MCP 或 Hook，不公开文件读取、仓库搜索、Patch、写文件、Shell 和子智能体工具。只允许显式白名单中的非项目能力，包括提问、计划、Goal、待办、用户启用的记忆和浏览器工具；直接创建子智能体同样拒绝。
5. AgentRuntime 仍需要一个内部路径构造 `ToolContext`，无项目 Turn 可以使用宿主当前工作区作为不可见占位路径，但 system prompt 不得包含该路径，且工具注册表不得包含任何能使用该路径的处理器。工作区切换继续在活动 Turn 期间由全局门禁拒绝。
6. 输入区左下角项目菜单底部显示“不在项目中”。选择它会新建不可变的无项目会话，不改绑当前会话，也不切换全局工作区；触发器和菜单勾选状态均从活动线程的 `inProject` 派生。
7. 无项目会话不查询 `@` 工作区文件候选或 `/` 项目 Skill 候选。工作台仍是用户直接控制的全局项目视图，不因此成为该会话的模型 Capability。

## 影响

- “不在项目中”成为可恢复、可审计的线程状态，而不是只存在于 `localStorage` 的展示分类。
- 一般对话可以继续使用模型、图片、计划、记忆和显式启用的浏览器能力，但不能静默读取宿主当前项目。
- 从无项目会话选择项目会创建新的项目线程；不可变工作区绑定仍不允许原地改写。
- JSONL event schema 升至 9，SQLite schema 升至 5；两者都对既有数据执行向前兼容迁移。

## 验收

- Repository 覆盖无项目创建、投影、拒绝绑定和 fork 保留状态。
- AppState 覆盖无项目解析不触发惰性绑定；system prompt 与工具白名单覆盖项目路径和项目工具不可见。
- desktop/narrow Playwright 覆盖左下角菜单位置、创建参数、无工作区切换、触发器文案、选中状态以及不触发 `@` 文件和 `/` 项目 Skill 候选。
