# ADR 0005：有界高级智能体运行时

- 状态：已接受
- 日期：2026-07-25

## 背景

Phase 9 引入计划、Goal、浏览器、搜索、记忆、模型回退、文档解析、评估和指标。这些能力会增加自治时间、外部访问、持久化数据和模型成本，不能只靠提示词约束。

## 决策

1. 计划按会话保存完整修订快照。步骤只能是待处理、活动、完成、失败或跳过；任意修订最多一个活动步骤。
2. Goal 由宿主持有 Token 和运行时间预算。活动、暂停、阻塞、完成和预算耗尽是显式状态；暂停会取消当前 Turn，终态不可恢复。
3. 浏览器使用成熟的 Chromium DevTools 客户端，默认关闭。启用、导航、交互、截图和取消都有独立审计；工具继续按外部访问风险审批。
4. 浏览器只接受 HTTP(S) URL，拒绝凭据、回环和私有网络目标。截图写入应用数据目录的有界产物区，不授予模型任意文件路径。
5. 仓库索引只读取工作区内受支持的文本文件，并限制文件数、单文件大小、结果数和预览长度。
6. 记忆默认关闭。每条记忆保存来源、创建/更新时间、删除状态和过期时间；用户可以编辑和删除，过期内容不进入模型上下文。
7. 模型回退只发生在尚未产生输出的可重试请求错误。取消、认证/请求错误、无效响应和中途断流不回退，避免重复副作用和重复文本。
8. 文档解析先校验工作区路径、文件类型和大小，再对文本、PDF 和 DOCX 使用有界提取。未知或超限格式失败关闭。
9. 评估使用录制 Provider 夹具，不依赖真实网络。指标以追加事件记录 Provider 延迟、Token、工具结果、回退和任务终态，并对日志大小设限。

## 影响

收益：自治预算、外部访问和记忆来源均可见、可取消、可审计；普通聊天继续在没有 Goal、浏览器或记忆时按原路径运行。

成本与限制：浏览器依赖本机 Chrome/Chromium；当前只维护一个受控浏览器会话；多端点共享同一供应商凭据；成本在未配置模型价格时明确标记为未知。

## 未采用方案

### 仅用系统提示词维护计划和预算

未采用，因为提示词不能保证唯一活动步骤、持久化、取消或预算终止。

### 中途断流后自动切换模型

未采用，因为已产生的文本或工具调用无法安全重放，可能造成重复写入和重复回答。

### 默认启用浏览器和长期记忆

未采用，因为两者扩大了数据访问范围，必须由用户显式开启并随时关闭。
