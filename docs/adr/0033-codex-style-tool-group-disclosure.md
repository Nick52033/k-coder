# ADR 0033：采用 Codex 风格的工具组折叠摘要

- 状态：已接受；逐项 `run_command` 详情展示于 2026-08-15 由 ADR 0034 修订，摘要卡片样式与多命令高度由同日的 `P10-101` 修订，摘要 logo 与箭头语义由同日的 `P10-102` 修订
- 日期：2026-08-15
- 关联：ADR 0010、ADR 0034、P10-043、P10-086、P10-090、P10-100、P10-101、P10-102

## 背景

连续工具活动已经按时间线聚合，但原有工具组复用了通用过程步骤的双边框摘要。外层 Turn 执行折叠、工具组折叠和逐项工具明细连续叠加时，完成态会显得过重，且“已完成”状态与外层终态重复。

Codex 的执行单元使用轻量单行摘要：状态标记位于左侧，动作标题和可选状态保持简短，展开箭头紧跟在标题行后，摘要不额外显示终端或扳手 logo。展开内容使用缩进和连接线表达从属关系。运行中的单元优先显示当前状态，完成后保留可审计的展开入口。

## 决策

1. 保留现有 `details` 语义、键盘操作、自动展开/收起和时间线分组边界，不改变 JSONL、Provider 历史或工具结果。
2. 工具组摘要改为“状态点 + 动作标题 + 箭头 + 可选状态”的紧凑单行布局，不显示终端或扳手 logo；箭头紧跟在标题后，收起时指向右侧，展开时显示下箭头，非完成态状态文字跟在箭头之后。完成态不再显示冗余的“已完成”，失败、取消、等待和运行状态继续显示状态文字。
3. 工具组摘要使用无边框、透明背景的轻量行，取消卡片外框、填充底色以及通用过程步骤的上下边框叠加；悬停只改变标题颜色，展开内容沿左侧细连接线缩进，逐项工具行取消重复分隔线。`run_command` 的逐项参数、输出与耗时展示由 ADR 0034 进一步收敛为命令文本和状态；其他工具继续保留适用的详情。
4. 状态点继续使用成功、品牌、错误和弱化墨色语义，摘要不再承担终端或扳手图标语义；逐项工具行仍可保留完成、失败、取消、等待和运行状态图标，运行中的旋转图标与状态点同时保留，以便在长时间工具调用期间快速定位活动。
5. `prefers-reduced-motion`、详情懒加载和用户手动展开能力继续复用既有折叠实现。
6. 连续纯命令组包含多个命令时，展开内容区最多显示 168px；长命令换行或命令数量较多导致内容超出后，只在该内容区纵向滚动。单命令和普通操作组继续使用自然内容高度。

## 影响

- 完成态连续命令组更接近 Codex 的轻量执行单元，透明行与连接线替代嵌套卡片，状态点和紧跟标题的右/下箭头保留必要的交互反馈，非完成态状态文字不改变箭头位置，且不会与外层 Turn 摘要争夺层级。
- 较多或较长命令不会无限拉长对话；滚动边界只影响多命令组，不浪费单命令或普通操作组的空间。
- 详情仍然可以逐项审计，旧历史和实时事件无需迁移。
- 依赖摘要文本的 E2E 选择器继续使用稳定的 `.turn-tool-group` 和标题文本；摘要图标选择器改为验证终端/扳手 logo 不存在，并验证收起右箭头与展开下箭头的切换，逐项工具行状态图标契约保持不变。

## 验收

- `pnpm exec tsc --noEmit` 通过。
- 工具组活动态/完成态 Playwright 折叠回归通过。
- Playwright desktop/narrow 视口截图确认完成态无卡片摘要、展开连接线、多命令滚动和运行态实时状态可见。
