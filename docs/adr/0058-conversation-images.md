# ADR 0058：对话图片展示与压缩后的视觉上下文

- 状态：已接受
- 日期：2026-09-10
- 关联：ADR 0009、0036、0037、0041、0048，P10-169

用户要求输入图片可被模型识别，回答中的图片直接展示并点击打开。旧 Markdown 渲染器把普通图片替换为名称；默认 URL 清理会移除 data URL；会话压缩仅保留图片数量，恢复后不再携带原图。

## 决策

1. 继续使用现有 ImageAttachment / UserContent 和四种 Provider 图片协议。显式配置为支持图片的普通 Chat Completions 模型不因 DeepSeek 名称启发式被强制改为纯文本；显式 deep_seek_chat_completions 仍为纯文本。配置声明不保证第三方服务的实际能力。
2. 压缩时保留最近一个含图片的真实用户消息批次，仍受输入最多 4 张、单张 4 MiB、合计 8 MiB 限制。恢复从原始 UserMessage 事件重建该批次，不把像素复制进摘要、不修改持久化协议，也不把文本摘要伪装成图片。纯文本模型恢复不携带像素。
3. Markdown 图片支持 HTTP(S)、有界 PNG/JPEG/GIF/WebP/BMP base64、工作区相对/绝对图片路径及浏览器截图制品名。远程图片自动展示并使用 no-referrer；这是对 ADR 0009 原先禁止远程图片自动加载的定向修订。原始 HTML、脚本 URL、file URI、SVG data 和带凭据 URL 继续拒绝。普通文字中的严格截图名在 Markdown AST 文本节点转换，代码、链接和已有图片节点不改写。
4. 所有可显示图片使用按钮缩略图，复用 ImagePreviewDialog。弹层使用 portal 避免正文布局限制，支持 Escape、关闭按钮、焦点回到触发按钮及禁止背景滚动。加载失败显示明确状态。
5. read_message_image(threadId, path) 是轻量 Tauri 边界：解析所属线程的项目工作区，再调用 workbench 的图片读取函数。无项目线程拒绝本地读取；绝对路径也必须 canonicalize 并留在工作区内，父目录、链接/目录联接逃逸拒绝。最多读取 4 MiB + 1 字节用于超限判定，按真实文件头判定栅格格式，不读取任意文本或执行文件。
6. 浏览器截图继续只读取宿主制品目录中的严格名称，读取前验证规范化路径未逃逸制品根及应用数据根，并限制读取字节数。

## 验证

Rust 覆盖压缩、恢复、文本模型隔离、显式视觉配置、路径/目录联接/内容/大小边界；Playwright 覆盖双视口发送、缩略图、远程/内嵌/工作区/截图预览、不安全来源及错误状态。隔离原生 Tauri 使用本机 HTTP Provider 断言实际 image_url 字节、压缩刷新后的原图恢复和真实 IPC 文件读取拒绝。
