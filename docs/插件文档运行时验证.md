# 文档、演示与表格插件运行时适配验证

日期：2026-09-14。范围：当前项目保留的 documents、presentations、spreadsheets 三个插件；没有恢复已删除插件、修改外部运行时、安装依赖或部署安装目录。插件启用和原生宿主验收由本次主任务统一记录。

## 已实现的本地执行路径

- documents 保留文档设计、样式、表格、审阅及 OOXML 指引，使用已安装 Python/docx 执行本地 DOCX 构建和验证。
- presentations、spreadsheets 的 Skill 名称修正为宿主支持的小写，保留原有编写与质量指引；使用已安装 artifact-tool 2.8.59 构建可编辑 PPTX 和带公式、缓存计算结果的 XLSX。
- 三个 Skill 都给出 `run_command` 可执行的工作区入口，不再要求不存在的 Codex dependency-loader、Google Drive import 或 live Excel 工具。云导入仍明确不支持；不能把本地文件保存表述为更新了云端文件。
- `scripts/plugin-artifact-runtime.ps1` 定位当前用户已安装的 Node/Python；ESM loader 只将 artifact-tool 公共包导入映射到该已安装包，其他导入交给 Node 正常解析。没有创建依赖目录联接，也没有复制外部运行时到仓库。
- presentations 原有 `artifact_tool_utils.mjs` 不再在工作区创建 `node_modules` 联接，关闭内部 local-granola 开发后端；工作目录先规范化、限制在当前项目并拒绝符号链接/目录联接。
- Launcher 校验入口是工作区相对文件，拒绝绝对路径、父级穿越、NTFS 流、链接及目录联接，原样保留子进程退出码。它是普通 Shell 子进程辅助工具，不能替代宿主 PolicyEngine 的审批、超时、取消或进程树管理；也不把模型字段升级为授权。

## 可复现命令

在源码根目录的 PowerShell 中执行：

```powershell
powershell -NoProfile -File scripts/plugin-artifact-runtime.ps1 -Action info
powershell -NoProfile -File scripts/plugin-artifact-runtime.ps1 -Action node -Script scripts/plugin-artifact-runtime.test.mjs
powershell -NoProfile -File scripts/plugin-artifact-runtime.ps1 -Action node -Script scripts/plugin-artifact-smoke.mjs -ScriptArguments --no-render
powershell -NoProfile -File scripts/plugin-artifact-runtime.ps1 -Action python -Script scripts/plugin-artifact-smoke.py
```

向实际 helper 传递多个参数时使用 PowerShell 数组，不要用字符串拼装 Shell 命令，例如：

```powershell
& ./scripts/plugin-artifact-runtime.ps1 -Action python `
  -Script .k-coder/plugins/documents/skills/documents/render_docx.py `
  -ScriptArguments @('docs/plugin-artifact-validation/validated-document.docx', '--output_dir', 'docs/plugin-artifact-validation/docx-preview')
```

上述 DOCX 渲染命令目前预期报告缺少 LibreOffice。不要把这一预期限制当作通过渲染验收。

## 保留的真实限制

1. **DOCX 排版渲染缺少 LibreOffice。** 实际调用原插件 `render_docx.py` 后，启动 `soffice` 返回 `FileNotFoundError / WinError 2`。文档可以生成、编辑和结构验证；没有声称页面布局完成目视验收。
2. **本机 artifact-tool 原生渲染退出异常。** 调用 XLSX/PPTX PNG 渲染后文件实际写成并可打开，但 Node 最终退出码为 `-1073740791`（Windows 原生异常）。通过绝对公共入口直接 import、绕过新增 ESM loader 后仍可复现；跳过渲染后同一构建流程退出 0。降低 Skia 线程数、显式正常退出都未消除异常，已保留原始退出码，未伪造命令成功。后续需要修复/更新本机原生渲染运行时，当前适配不擅自修改外部依赖。
3. **Google Docs/Sheets 和实时 Excel 没有连接器。** 当前能力是本地文件工作流；如需云端修改，必须实际接入对应已授权工具。图片生成同样只在工具目录实际提供该能力时使用。
4. 此处没有独立重复执行 Rust/前端质量门槛；由主任务对整个共享工作区统一验证。这里也不宣称桌面工作流或安装部署完成。
