# `@` 文件引用结果分类验证

## 范围

用户在 Composer 输入 `@` 时，工作区文件候选不再使用一个平面列表，而是按文件扩展名归入以下分组：

- 代码
- 文档与数据
- 配置
- 样式与资源
- 其他文件

分组只发生在前端展示层。后端 `search_workspace_files` 的查询、50 条结果上限、工作区路径校验和 `@path` 插入格式均保持不变。每个候选仍保留搜索返回的原始索引，因此上下键、Enter/Tab 和鼠标选择不会改变语义；组内顺序也保持后端匹配顺序。

## 交互调整

- 面板标题显示当前候选总数。
- 每个非空分组显示图标和分组数量。
- 代码、文档与数据、配置、样式与资源使用明确的扩展名集合；未知扩展名归入“其他文件”。
- `/Skill` 候选继续使用原有单列表和启用状态展示。
- 分组标题使用 `role="group"` 和可读数量，候选仍使用 `role="option"`，保持键盘和辅助技术语义。
